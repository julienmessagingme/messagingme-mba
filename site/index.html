Quatre entrées, une seule conversation.

Engage Me relie vos campagnes et vos canaux, puis confie chaque conversation à qui vous choisissez.

  • Campagne pushVos offres et relances, au bon segment
  • Chaîne WhatsAppUn post de votre chaîne ouvre l’échange
  • Publicité Click-to-WhatsAppLe clic sur l’annonce lance le bon scénario
  • RCSPrend le relais quand WhatsApp ne passe pas
  • Vos agents IAVos règles, vos outils, vos connaissances
  • Meta Business Agent natifL’agent de Meta, configuré depuis la console
  • Votre équipeDans une boîte partagée, elle reprend la main

Chaque conversation est lue : intention d’achat, urgence, satisfaction, risque de churn. Vous savez qui relancer, et qui retenir.

Branchez Engage Me sur votre système.

Contacts, messages WhatsApp et RCS, scénarios : pilotez tout depuis vos outils avec l’API, ou depuis un assistant IA avec le serveur MCP.

Documentation de l’API Serveur MCP 
# Envoyer un message par l’API
curl -X POST https://api.messagingme.app/v1/messages/whatsapp \
  -H "Authorization: Bearer mba_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"externalId":"crm-7781",
       "text":"Votre commande 8412 est prête, vous pouvez passer la retirer."}'

# Brancher un assistant sur le serveur MCP
claude mcp add --transport http mba https://api.messagingme.app/mcp \
  --header "Authorization: Bearer VOTRE_CLE"
