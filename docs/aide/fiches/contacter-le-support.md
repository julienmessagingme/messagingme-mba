# Nous écrire depuis la console

La page Support, en bas du menu de gauche, porte un formulaire de contact : un sujet, un message, et
« Envoyer ». Votre message arrive directement chez notre équipe.

**La réponse part vers l'adresse du compte avec lequel vous êtes connecté**, et elle ne se choisit pas dans
le formulaire : l'écran vous rappelle laquelle c'est, juste sous le titre. Si vous voulez qu'un collègue
reçoive la réponse, c'est donc à lui d'écrire, depuis son propre compte.

Une fois le message parti, l'écran vous le confirme en nommant l'adresse qui recevra la réponse, et vous
propose d'en envoyer un autre.

**Vous pouvez envoyer jusqu'à cinq messages par minute.** Au-delà, un message vous invite à réessayer un peu
plus tard. C'est une protection contre les envois accidentels en rafale, pas une limite de ce que vous avez
le droit de nous demander.

Pour qu'on vous réponde vite, dites dans le sujet de quel écran vous parlez, et dans le message ce que vous
attendiez et ce qui s'est passé à la place.
