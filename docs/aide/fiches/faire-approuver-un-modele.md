# Créer un modèle et le faire approuver

Un modèle est un message que WhatsApp valide avant que vous ayez le droit de l'envoyer. C'est le passage
obligé pour écrire à quelqu'un qui ne vous a pas répondu récemment.

Vous le composez dans l'écran Modèles. Un modèle simple porte un corps de texte, éventuellement un en-tête
(texte, image ou vidéo), un pied de page, et des boutons. L'en-tête texte et le pied de page sont limités à
soixante caractères et n'acceptent pas de variable. Vous pouvez aussi créer un carousel : un message
d'introduction commun, puis de deux à dix cartes avec image, chacune portant les mêmes boutons.

Vous choisissez la langue dans une liste, puis vous soumettez. WhatsApp répond en général en quelques
minutes, parfois quelques heures. L'écran suit le statut pour vous.

**Les variables** se notent entre doubles accolades et sont remplacées au départ par ce qu'il y a dans la
fiche du contact. Un contact dont le champ est vide ne reçoit pas le message : WhatsApp refuse un modèle
dont une variable manque, et vous le retrouvez dans les destinataires écartés de la campagne, avec son
motif.

**Les clics sur vos boutons de lien sont comptés**, sans que vous ayez rien à faire. Vous saisissez votre
lien normalement, et la console vous remontre toujours le vôtre. Les compteurs se lisent dans Analytics.
Deux limites, dites franchement : seuls les **boutons** sont suivis, pas un lien écrit dans le corps du
message ; et un modèle déjà approuvé garde l'adresse figée chez WhatsApp, ses clics restent donc anonymes.
